# Android Boost USB

Prototype Android app (0.1.0) for device info, a basic suspicious-name scan, and safe optimization tips.

**Important:** This is not a malware antivirus. Name-based detections can be false positives; do not uninstall apps solely because they are flagged. The app does not automatically remove apps or modify system settings.

## Build
The GitHub Actions workflow `.github/workflows/android-build.yml` builds a debug APK and uploads it as an artifact.
